# Замер: что считать и как читать

Замер отвечает на один вопрос: стало ли лучше по форме, не стало ли хуже по
смыслу. Он не выносит приговор тексту и не решает за автора.

## Четыре числа

1. **Плотность маркеров** — сколько находок на 1000 слов.
2. **Разброс длин** (CV) — отношение стандартного отклонения длины предложений
   к среднему.
3. **Доля абзацев с коротким финалом** — абзацы, где последнее предложение
   короче 75 знаков, делить на все абзацы тела.
4. **Усушка** — на сколько процентов стало меньше слов.

Дополнительно запиши число слов до и после.

## Команда

```bash
python3 <папка навыка>/scripts/diagnose.py файл.txt
python3 <папка навыка>/scripts/diagnose.py файл.txt --json
python3 <папка навыка>/scripts/diagnose.py файл.txt --profile speech
python3 <папка навыка>/scripts/diagnose.py файл.txt --profile transcript
python3 <папка навыка>/scripts/diagnose.py файл.txt --only rhythm
cat текст.txt | python3 <папка навыка>/scripts/diagnose.py -
```

Коды выхода: `0` — в пределах порогов, `1` — есть провалы, `3` — ошибка ввода.
Код `1` не запрещает выдавать текст: он показывает, где смотреть.

## Как читать

| Число | Ориентир | Что значит |
|---|---|---|
| CV | ≥ 0.55 | живой рваный ритм |
| CV | 0.40–0.55 | средний, типично для технического текста |
| CV | < 0.40 | машинная ровность |
| Короткие финалы | до 35 % | норма для письменного текста |
| Короткие финалы | 35–45 % | много рубленых концовок |
| Усушка | ≤ 12 % | допустимо |
| Плотность | 8 / 1000 | ориентир для письменного текста |

Пороги плотности для других профилей: 12 / 1000 для речи под суфлёр,
16 / 1000 для расшифровки.

Потолок усушки 12 % действует на тексте от 150 слов. На коротком тексте он
не применяется: удаление пустой подводки может дать больше 12 %.

Жёсткий гейт типографики срабатывает только на невидимые символы: нулевой
ширины, BOM, разделители строк и лишнее экранирование. Длинное и короткое тире,
кавычки, многоточие и неразрывный пробел находкой не считаются.

## Числа — диагностика, а не приговор

Пороги `diagnose.py` сняты с корпуса одного автора. Два из них прямо спорят
с правилами этого навыка:

- стаккато имеет лимит ноль, а короткие фразы в чате и посте нормальны;
- безличные конструкции считаются находкой, а навык их не переделывает.

Поэтому здесь число идёт в отчёт как динамика «было → стало». Провал по числу
не блокирует выдачу. Он требует строки в отчёте: что осталось и почему.
Не подгоняй текст под число и не подгоняй знаменатель: подгонка отчёта хуже
плохого числа.

## Калибровка под автора

Калибровка нужна, когда своих текстов достаточно и пороги по умолчанию
ругают то, что автор считает хорошим.

```bash
python3 <папка навыка>/scripts/diagnose.py --calibrate КОРПУС/ --name имя
```

- Нужно 5–10 готовых текстов автора в `.md` или `.txt`.
- Скрипт печатает плотности по файлам и осям и блок порогов по p90.
- Блок не вставляется в навык. Он нужен как ориентир: сравни свои числа
  с p90 автора.
- Меньше пяти файлов — не калибруй. Один текст ничего не доказывает.
- Корпуса нет — скажи это прямо. Не выдавай пороги по умолчанию за
  измеренные под автора.

## Ручной замер без Python

Считай по тексту в 300 слов или по всему тексту, если он короче.

- **Плотность.** Число находок × 1000 / число слов.
- **CV.** Возьми 10–15 предложений, посчитай длину каждого в словах, найди
  среднее и стандартное отклонение. CV = отклонение / среднее. Грубая
  проверка: если все предложения по 10–20 слов, CV низкий.
- **Короткие финалы.** Число абзацев, где последнее предложение короче
  75 знаков, раздели на число абзацев тела и умножь на 100.
- **Усушка.** (слов до − слов после) / слов до × 100.

## Если после правки стало хуже

1. Проверь знаменатель: не выпали ли абзацы из замера.
2. Стало хуже по ритму — верни исходную формулировку.
3. Стало хуже по маркерам — найди правку, которая породила новый маркер.
4. Не крути четвёртый проход. Потолок — три.
5. Запиши ухудшение в отчёт честно.

## Чего замер не видит

- Смысл, иронию, голос автора.
- Ложные срабатывания на законных терминах.
- Цитаты, код, таблицы и строки списков: они исключены из счёта.
- Ритм в профиле `transcript`: пунктуацию ставила распознавалка, считать
  по ней нельзя.
